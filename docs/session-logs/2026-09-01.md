# Session Log: 2026-09-01

## Built

- Made `versionCode` / `versionName` env-driven in `app/build.gradle.kts`
  (`VERSION_CODE` / `VERSION_NAME`, defaulting to `1` / `1.0`). Previously both were
  hardcoded, so no rebuild could ever register as an update on a tester's phone.
- Extended `.github/workflows/android-release.yml`: one signed build now emits both the
  `.aab` (Play Console) and an `.apk` (installable on a phone), uploads both as
  artifacts, and optionally publishes a GitHub Release with the APK attached. The
  workflow takes a `version_name` input and derives `VERSION_CODE` from
  `github.run_number` so each dispatch outranks the previous install.

  setup (USB + wireless adb), the `installDebug` update loop, `scrcpy` for mirroring the
  phone to the PC, the debug/release signature gotcha, and the three distribution tracks
